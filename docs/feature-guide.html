Progress Tracking & Custom Categories

Feature guide for staff — how it works

Two new capabilities: a colour-coded progress graph for every student with automatic special-ed alerts when a child declines, and the ability to create your own tracking categories and pick their colours.

📈 The Progress Graph

  • Open a student → Progress tab.
  • Every kind of mark is a different colour line over time.
  • Click a colour chip to view one aspect; click All marks for everything.
  • Trend arrows show ⬆️ up, ⬇️ down, ➖ steady, with the latest score.

👥 Student vs. Class

  • Select a single aspect to reveal a dashed class-average line.
  • Each aspect shows a student vs. class comparison.
  • Classes are colour-graded 🟢 Top / 🟠 Average / 🔴 Weaker.

🚨 Automatic Special-Ed Referral

  • Trigger: a student's score drops on the same aspect more than once.
  • A popup appears the moment the mark is entered (and as a banner on the profile), listing the exact aspects and score history (e.g. “Declined in Learning 2 times (5→3→2)”).
  • Review/edit the reason, choose a priority (Low / Normal / High / Urgent).
  • Send to Special Ed → the child is added to the evaluation queue and an email is sent automatically to the special-ed team with the reason. Not now → nothing is sent.

🎨 Add Your Own Categories (Pick a Colour)

  1. Go to Settings → Tracking tab.
  2. In Mark Categories, click the colour square and choose any colour.
  3. Type a Name (e.g. “Kriah”), optionally a Yiddish name, then click Add.
  4. Anytime: click a colour to recolour, toggle Active/Hidden, or 🗑️ delete custom ones (built-ins are protected).

New categories appear instantly in the Grades entry screen and as their own coloured line on every student's graph.

One-time setup (Settings → Tracking): enter the special-ed team's email address(es) for referral alerts (comma-separated; falls back to special-ed staff emails), and set the decline sensitivity (number of drops before prompting — default 2).
Cloud-based — updates on all devices automatically. No installation required.
